# Triage Labels

Mapeamento dos 5 papéis canônicos de triagem utilizados pelas skills de engenharia para o issue tracker local.

| Label em mattpocock/skills | Label no Tracker Local | Significado |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | Requer avaliação inicial do desenvolvedor / mantenedor |
| `needs-info` | `needs-info` | Aguardando esclarecimento adicional ou validação de regras |
| `ready-for-agent` | `ready-for-agent` | Especificação completa, pronta para execução autônoma do agente |
| `ready-for-human` | `ready-for-human` | Requer intervenção ou aprovação manual humana |
| `wontfix` | `wontfix` | Não será implementado ou foi descartado |
